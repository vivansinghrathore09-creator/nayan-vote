## ?? Key Features

- **Near-Infrared Dual Iris Recognition**: Eye-level contactless scan authenticates voters in under 1.8 seconds.
- **Multimodal Universal Access**: Voice-guided voting and touch interface in **9 Indian Languages** (Hindi, English, Bengali, Telugu, Marathi, Tamil, Gujarati, Kannada, Malayalam).
- **Absolute Secret-Ballot Privacy**: Ephemeral session tokens decouple voter identity from the ballot. Biometrics are wiped immediately from RAM.
- **Offline-First Security**: Air-gapped cryptographic architecture with zero cloud or internet dependency.
- **Physical Verification (VVPAT 2.0)**: Instant thermal printed receipt visible behind a sealed chamber for 7 seconds.
